# Verifying UniCore downloads

Official UniCore releases publish SHA-256 checksums alongside release artifacts.

Always verify a binary archive before installation.

## Linux

Download the release archive and `SHA256SUMS`, then run:

```bash
sha256sum --check SHA256SUMS
```

A valid file reports `OK`.

To verify one archive manually:

```bash
sha256sum unicore_<version>_linux_arm64.tar.gz
```

Compare the output with the matching entry in `SHA256SUMS`.

## macOS

Use:

```bash
shasum -a 256 unicore_<version>_linux_amd64.tar.gz
```

## Supply-chain metadata

Release builds are designed to include a CycloneDX SBOM. Checksums and SBOM files are generated by the private UniCore release pipeline and published together with the matching release.

Do not install a file if its checksum does not match the checksum published in this repository.
