# ForgeCore releases

ForgeCore release artifacts are published through the shared Olympus Releases hub.

- Stable feed: `channels/forgecore/stable.json`
- Public release tag prefix: `forgecore-`
- Source repository: `Jojje84/ForgeCore`

Prerelease tags such as `v0.1.0-beta.20` are published as GitHub prereleases using
the public release tag `forgecore-v0.1.0-beta.20`. They do not update the stable feed.

Stable releases update only the ForgeCore channel after artifact verification succeeds.
